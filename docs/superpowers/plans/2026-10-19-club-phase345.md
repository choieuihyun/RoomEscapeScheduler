## Global Constraints

- 계약 원본은 `작업명세서.md` §4.7~§4.10. 바꿔야 하면 문서부터 고치고 서버 세션에 알린다.
- 시각은 분 정수, 화면 입력은 24시간제, 자정 넘김은 "앞 시각 ≥18:00 이고 뒤 시각 <06:00" 일 때만(§4.7). 표시는 `다음날 00:30`. '오늘'은 `todayKst()`. 날짜 표기는 `clubEvents.ts` 의 `dayLabel`/`longDayLabel`/`relDay`.
- **칩은 다우오피스 계열**(목업 ① 칩): 상태 칩 = 카드 바탕 + 1px 색 테두리 + 색 글자(협의 중 보라·예약 전 주황·예약 완료 초록·마감 회색), 고르는 칩 = 선택 시 진한 테두리(`--ink`)+굵은 글자 / 아니면 옅은 테두리, 숫자 = 채운 동그라미(지난 것 회색). 모든 색은 `floduler.css` 토큰(:root + 다크 두 블록)으로, 대비 4.5:1 이상.
- 서버 에러는 본문 `message` 를 그대로(`sayClub`). 새 API 가 본문 없는 404 면 그 기능만 숨기고 나머지는 그대로.
- 조합 계산·공유 링크(`#s=`·`#z=`)·테마 불러오기·개인 일정 저장은 로그인 없이(개인 일정은 로그인만으로) 지금처럼 동작해야 한다.
- 화면 문구는 해요체·사람 말. ADMIN 은 "운영진".
- 확인 스크립트는 scratchpad, 헤드리스 크롬 규칙(CLAUDE.md) 준수, 실제 운영 서버는 부르지 않는다.
- 커밋에 `Co-Authored-By` 없음. 푸시는 배포 지점에서 사용자 승인 뒤에만. 린트 경고 172 를 넘기지 않는다.

## Review Focus

1. **날짜 미정 일정이 범위·목록·홈에 섞일 때** — 후보 일부만 범위 안, 날짜를 정했다가 다시 미정으로, 내 다음 일정(미정은 빼야 함), 캘린더 후보 칩. → Task 3 테스트(`mergeRange`·`sortKeyDate`·`nextMine`).
2. **수정할 때 후보가 날아가지 않게** — "날짜 정하기"로 정할 때 후보를 지우지 않고(`candidates` 를 보내지 않음), 후보를 고칠 때만 목록을 보낸다. → Task 4 테스트(`toInput`).
3. **되는 시간 교집합** — 종일·시간대·자정 넘김이 섞이거나, 아무도 응답 안 했거나, 한 명만 됐을 때. 교집합이 비면 "겹치는 시간 없음". → Task 3 테스트(`candidateSummary`).
4. **협의 도우미가 "시간표를 아직 안 모은 날"을 "열린 테마 없음"으로 보이면 안 됨**(`collected: false`), 기록 없는 참여자는 따로 경고. → Task 8 테스트·헤드리스.
5. **알림을 못 받는 경우마다 맞는 안내** — 권한 거부, 아이폰 홈 화면 미설치, 카카오톡 안 브라우저, 테스트 알림 429. 알림을 누르면 `#e=<id>` 로 그 일정이 열림. → Task 10·11 테스트(`pushState`)·헤드리스.

**Files:** Modify `EventPanel.tsx`(또는 새 `EventHelper.tsx`), `HomePage.tsx`, `CalendarPage.tsx`, `SchedulerPage.tsx`, `floduler.css`; Test `played.test.ts`(도우미 순수 부분)

- 목록: 홈 "가까운 일정" 줄·캘린더 칩·상세 머리에 `해 봄 n`(n>0 일 때만).
- **협의 도우미**(목업 ② 왼쪽 아래 "어떤 테마?"): 협의 중이거나 날짜가 정해진 일정, 참여자만. 기준 날짜 = 일정 날짜, 미정이면 `candidateSummary` 맨 위 날짜(바꿀 수 있는 날짜 고르기). `freshThemes` 결과:
  - `collected: false` → `'이 날은 아직 시간표를 모으지 않았어요. 가까워지면 다시 볼 수 있어요.'` (**Review Focus 4** — "열린 테마 없음"과 다른 문구)
  - `collected: true` 이고 빈 목록 → `'이 날 열린 테마가 없어요.'`
  - `missing` 이 있으면 접힌 줄 `'이 매장들은 그날 시간표가 없어요(아직 안 열렸거나 쉬는 날)'` + 매장·지점 목록
  - `noRecord` 가 있으면 경고 줄 `'○○ 님은 해 본 테마 기록이 없어요. "아무도 안 해 봄"이 틀릴 수 있어요.'`
  - 줄: 체크 · 테마 · 매장·지점·소요 · 회차 시각들(매진 취소선) · 칩 "아무도 안 해 봄"(초록 정보 칩) 또는 "해 봄 n"(주황). 아래 "우리가 시간표를 모으는 매장만 보여요." + "고른 테마 n개로 조합 계산" → 계산 화면에 그 테마들(`ServerTheme` 모양 그대로 — `s.addServerThemes` 를 찾아 쓴다)을 넣고 이동.
- 순수 테스트: `freshMessage(dto)` 세 갈래 문구, `noRecordNames`.
