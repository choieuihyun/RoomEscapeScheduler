# 방탈출 스케줄러

방탈출 테마를 하루에 연달아 예약할 때, **겹치지 않는 모든 조합을 계산해 대기 시간이 어디에 얼마나 생기는지** 보여주는 단일 페이지 웹 도구.

```bash
npm run dev     # http://localhost:5173
npm test        # 인수 테스트 (29개 검사)
```

`index.html` 을 브라우저에서 그냥 열어도 조합 계산은 전부 동작한다. 빌드 없음, 의존성 0개.

개발 서버는 **127.0.0.1(루프백)에만 묶인다** — 같은 와이파이에 붙은 다른 기기에서는 접속되지 않는다.
폰에서 열어보는 등 일부러 같은 망에 노출하려면 `HOST=0.0.0.0 npm run dev`.

## 예약 화면 캡처로 회차 넣기 (선택)

회차 칸에 스크린샷을 **붙여넣거나 끌어다 놓으면** 시간과 매진 여부를 읽어온다.
브라우저는 API를 직접 부를 수 없으므로 개발 서버가 프록시 역할을 하고, 키는 서버에만 머문다.

```bash
ANTHROPIC_API_KEY=sk-ant-... npm run dev
```

키가 없으면 OCR만 꺼지고 나머지는 그대로 동작한다.
