# Floduler

방탈출 테마를 하루에 연달아 예약할 때, **겹치지 않는 모든 조합을 계산해 대기 시간이 어디에 얼마나 생기는지** 보여주는 단일 페이지 웹 도구.

```bash
npm run dev     # http://localhost:5173
npm test        # 인수 테스트 (44개 검사)
```

`index.html` 을 브라우저에서 그냥 열어도 조합 계산은 전부 동작한다. 빌드 없음, 의존성 0개.

개발 서버는 **127.0.0.1(루프백)에만 묶인다** — 같은 와이파이에 붙은 다른 기기에서는 접속되지 않는다.
폰에서 열어보는 등 일부러 같은 망에 노출하려면 `HOST=0.0.0.0 npm run dev`.

## 예약 화면 캡처로 회차 넣기

카드의 **이미지 첨부** 버튼(또는 붙여넣기·드래그)으로 스크린샷을 넣으면 회차 시간을 읽어온다.

인식은 **브라우저 안에서** 돈다 — 이미지가 서버로 나가지 않고, API 키도 과금도 없다.
엔진(PaddleOCR)은 `vendor/` 에 들어 있어 CDN 없이 오프라인에서도 동작하며, 첫 사용 시 약 18MB를 한 번 읽는다.

읽어오는 것은 **시간뿐**이다. 매진 여부는 읽지 않는다.

## 동호회에서 같이 쓰기

배포는 **GitHub Pages** 정적 호스팅 하나로 끝난다. 서버도, 계정도, DB 도 없다.

```
https://choieuihyun.github.io/RoomEscapeScheduler/
```

켜는 법 — 저장소 **Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`** → Save.
1~2 분 뒤 위 주소가 열린다. 이후 `main` 에 푸시하면 자동으로 갱신된다.

루트의 빈 파일 `.nojekyll` 은 지우면 안 된다. GitHub Pages 는 기본적으로 Jekyll 로 한 번 걸러
내보내는데, Jekyll 의 기본 제외 목록에 `vendor/` 가 들어 있어 **이미지 인식 엔진이 통째로 누락된다**.
`.nojekyll` 이 그 처리를 끈다.

### 각자 쓰고, 결과만 주고받는다

동시 접속이나 공동 편집 같은 건 없다. 각자 자기 브라우저에서 열어 쓰고, 나온 결과를 두 가지로 넘긴다.

| 방법 | 버튼 | 붙여넣으면 |
|---|---|---|
| **일정 복사** | 결과 카드의 복사 | `10:20 - 11:30 범계` 처럼 사람이 읽는 글 — 단톡방에 그대로 |
| **링크 복사** | 상단 `링크 복사` | 입력값이 통째로 담긴 주소 — 열면 상대 화면에 그대로 재현된다 |

링크에는 테마·소요시간·회차가 전부 주소 안에 들어간다(5테마 × 10회차 기준 약 800자).
서버에 저장되는 것이 없으므로 **링크를 잃어버리면 그 시간표도 사라진다.**

## 계정 만들고 일정 저장하기

로그인하면 **짠 일정을 계정에 쌓아 둘 수 있다** — `하고 싶은 일정` 과 `했던 일정` 으로 나뉜다.
아이디와 비밀번호만 받는다. 이메일도, 인증 메일도 없다.

로그인은 **부가 기능**이다. 아래 설정을 하지 않아도 조합 계산·이미지 인식은 그대로 돌아가고,
로그인 버튼을 누르기 전까지는 관련 코드가 한 바이트도 내려오지 않는다.

### 한 번만 하는 설정 (저장소 주인)

무료로 끝난다. [Firebase Spark 요금제](https://firebase.google.com/pricing)는 **카드 등록이 없고**,
한도(하루 읽기 5만·쓰기 2만)를 넘기면 청구되는 게 아니라 그날치가 잠긴다.
동호회 규모에서는 닿을 일이 없는 숫자다.

1. [console.firebase.google.com](https://console.firebase.google.com) → **프로젝트 만들기**
   (Google 애널리틱스는 꺼도 된다)
2. **빌드 → Authentication → 시작하기 → 이메일/비밀번호 → 사용 설정**
3. **빌드 → Firestore Database → 데이터베이스 만들기** → 위치는 `asia-northeast3` (서울)
4. 만들어진 뒤 **규칙** 탭에 [`firestore.rules`](firestore.rules) 내용을 그대로 붙여넣고 **게시**
5. **프로젝트 설정 → 내 앱 → 웹(`</>`) 추가** → 나오는 `firebaseConfig` 값을
   [`firebase-config.js`](firebase-config.js) 에 옮겨 적는다
6. **Authentication → Settings → 승인된 도메인**에 `choieuihyun.github.io` 추가
7. 커밋 & 푸시

4번을 건너뛰면 안 된다. Firestore 기본값인 "테스트 모드" 는 **누구나 남의 문서를 읽고 쓸 수 있고**,
30일 뒤에는 반대로 전부 잠긴다.

`firebase-config.js` 의 값은 비밀이 아니다 — 브라우저에 그대로 내려가는 "어느 프로젝트인가" 주소이고,
실제 보호는 4번의 규칙이 한다. 저장소에 그대로 커밋해도 된다.

### 쓰는 법 (동호회원)

로그인 → 조합 계산 → 마음에 드는 결과에서 **저장** → 날짜와 `하고 싶음`/`했음` 을 고른다.
저장한 일정은 페이지 아래 **내 일정** 에 쌓이고, `불러오기` 를 누르면 그때 넣었던 회차가 그대로 되살아난다.

저장되는 것은 **확정된 시간표**(누가·몇 시에·어디까지)와, 다시 짜 볼 수 있게 하는 입력값이다.
지나간 일정이 나중에 계산 로직이 바뀌었다고 달라지면 안 되므로, 시각은 그때 그대로 굳혀 둔다.

> **비밀번호를 잊으면 되찾을 방법이 없다.** 메일 주소를 받지 않기 때문이다.
> 다른 곳에서 쓰는 비밀번호를 재사용하지 말 것.

## 구성

```
index.html           앱 전체 (마크업 + 스타일 + 로직)
serve.mjs            개발 서버 (Node 내장 모듈만, 정적 서빙 전용)
test/acceptance.mjs  인수 테스트 — index.html 의 로직을 직접 실행
.nojekyll            GitHub Pages 가 vendor/ 를 걸러내지 않게 하는 빈 파일
cloud.js             계정·일정 보관 (로그인을 눌러야 내려온다)
firebase-config.js   Firebase 접속 정보 — 비우면 로그인 기능만 꺼진다
firestore.rules      Firebase 콘솔에 붙여넣을 접근 규칙
```
